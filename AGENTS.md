# Standalone PEQ

This public project adds PEQ while preserving the original XM5 media workflow. Read README.md and docs/BUILD.md for scope and build inputs. Keep music scanning, cover handling and ordinary card layouts on their stock paths; the separate xm5-management project owns managed-library changes.

The published firmware is PEQ08 / v0.1.0-a. The owner confirmed it usable on one device. Changes to documentation or repository organization do not extend that hardware acceptance.

Keep official inputs, toolchains, release binaries and local work under ignored .local/. Use the explicit build guide with original V2.43 inputs. Current release metadata and SOURCE-MANIFEST.json must match the actual source tree; preserve the original firmware BIN hashes during documentation-only changes.

No device/card operation or outgoing email is authorized by repository maintenance. Publish this project publicly only within the user's requested scope. Stock software/assets and third-party components retain their own rights.
